## Curation Notes

- Initial drafts, placeholder prompts, raw document caches, local demo packages, intermediate run outputs, and duplicate report builds are intentionally excluded from the formal agent repository.
- Retained files are either owner/collaborative research outputs, final workflow/prompt materials, final case reports, or supporting certification/evidence artifacts.
- Do not infer final legal, accounting, valuation, investment, or transaction advice from this package.
