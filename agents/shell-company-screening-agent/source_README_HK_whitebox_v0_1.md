# HK Shell Screening Agent - Source And Curation Note

This note replaces the earlier white-box all-files map. The public agent repository is intentionally curated: it keeps the highest-value workflow, prompt, case-study, and certified-code materials while excluding drafts, raw caches, local demo packages, placeholder scaffolds, and intermediate run folders.

## Source Lineage

- Early white-box source: `HK_Shell_Screening_Agent_v0.1/`
- Full workflow source: `deliverables/HK_Shell_Screening_Agent_FULL_WORKFLOW_v0.4/`
- Certified implementation source: `certified-shell-company-screening-agent/`
- Demo lineage: `shell-screening-demo/`, represented in this package by `03_case_studies/tuntun_hk/demo_README.md` only.

## Public Repository Shape


## Retained Material

- `01_business_workflow/full_workflow_v0_4_start_here/` keeps the final workflow overview, ER/BRB positioning, PCE positioning, and workflow tables.
- `02_prompts/` keeps the canonical shell screening prompt plus the certified trace and case-study generation prompts.
- `03_case_studies/tuntun_hk/` keeps the owner/collaborative Tuntun/TonTon HK case input, reports, certification files, selected evidence tables, and demo README.
- `04_agent_core/certified_shell_src/` keeps the final certified shell source code retained as the public agent-core implementation.

## Excluded From The Formal Repository

- White-box scaffolding and generic task-boundary fragments.
- Raw HKEX/AkShare document caches and bulk raw data snapshots.
- Drafts, scratch CSVs, regeneration scripts, and temporary tables.
- Placeholder audit scaffolds superseded by the retained certification/PCE artifacts.
- Duplicate report builds, temporary PDF folders, manual-formatting work files, and delivery zips.
- Local demo source folders and one-off preview packages.

## Interpretation

The retained case is a research/certification rescue materials, not legal, accounting, valuation, investment, or transaction advice. Certification status and caveats must be read from the retained delivery certificate, readiness result, PCE audit, and evidence tables.
