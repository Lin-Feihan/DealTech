# Evidence and certification

Every material conclusion must retain a recoverable Source, specific Evidence, a Claim, exact locator, source-quality metadata, limitations and counterevidence. Missing information remains an Unknown; management representation remains labelled; model prose and search snippets are not evidence.

Calculations register formula/version, inputs, units, currency, period, perimeter, assumptions, output and linked Claims. Required Block B calculations must independently replay with `PASS` before entering Block C. A failed or missing replay is a calculation Gap, not zero.

The control order is admission → calculation replay where required → PCE precheck → ER/BRB evidence-row assessment → final PCE delivery control → business Gate. PCE decides whether a Claim is deliverable (`Certified`, `Certified with Caveat`, `Needs Human Review`, `Not Certified` or internal trace only). ER/BRB records evidence reliability and risk signals. Neither control determines Strategic Fit, valuation, purchase price, returns or Go/No-Go.

Gate A tests the Strategic Thesis; Gate B tests value creation, pricing, financing and returns; Gate C tests diligence, regulatory, integration and downside risk. Delivery verification separately checks the report manifest, lineage, replay, caveats and blocked Claims.
