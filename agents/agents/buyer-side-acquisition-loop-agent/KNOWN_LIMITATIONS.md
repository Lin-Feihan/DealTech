# Known limitations

- The public full-pipeline demo uses recorded, fictional evidence and does not establish current market facts.
- No non-confidential live full-pipeline smoke test has been authorized or run for RC1.
- Live mode requires the optional OpenAI dependency, a configured model/API credential, explicit provider and attachment permissions, and `--enable-live`; CI never enables it.
- Public-source research cannot replace private financial, customer, tax, technology, cybersecurity, regulatory or integration diligence.
- The recorded XLSX path uses local OOXML extraction; formulas/macros are not executed.
- Editable installation is the supported RC1 packaging path because prompt/schema assets remain in the adjacent agent asset directory.
- Resume requires the original case file and unchanged hashed completed-stage artifacts.
- The repository has no approved software license yet. License selection is a pending user decision.
- Decision State and delivery certification are decision support, not investment, legal, financial or transaction approval.
