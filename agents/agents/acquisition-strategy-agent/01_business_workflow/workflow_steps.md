# Workflow Steps — Acquisition Strategy

1. Select perspective: buyer-side or target-side.
2. Load perspective-specific input setting, source registry, evidence table, research trace, and claim map.
3. Buyer-side evaluates valuation, strategic rationale, deal attractiveness, integration risk, synergy, and go/no-go recommendation.
4. Target-side evaluates offer attractiveness, standalone case, strategic alternatives, fairness, board response, and accept/reject/negotiate recommendation.
5. Execute ER/BRB separately for each perspective.
6. Execute PCE with strict source replay and calculation replay blockers.
7. Generate separate outputs under each view directory.
