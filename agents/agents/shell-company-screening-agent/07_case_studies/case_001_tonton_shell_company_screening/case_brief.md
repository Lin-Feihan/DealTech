# Case Brief — TonTon / Tuntun HK Shell Company Screening

This case migrates the latest certified shell-company screening repository into the unified DealTech framework. The mandate is to screen HK-listed companies for possible restructuring, asset injection, control transaction, or business-combination platform fit for TonTon / Tuntun Health.

The case preserves the upstream trace, ER/BRB scoring, PCE audit, and final delivery artifacts from the latest cleaned package. It does not use old duplicate shell demo pages as main output.
