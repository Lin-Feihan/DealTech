# SPAC Target Acquisition Agent

Public rescue materials for the Soren SPAC Target Acquisition Agent research work.

This folder keeps only the highest-value public materials: workflow/methodology, final prompts, the Soren case-study reports, original and derived case inputs, selected supporting evidence tables, and a demo README. Initial drafts, process logs, local demo packages, intermediate run folders, placeholder citation ledgers, and regeneration scripts were removed.

## Source Lineage

- Main early agent source: `US_SPAC_Target_Acquisition_Agent_v1/`
- Historical delivery zips: `outputs/US_SPAC_Target_Acquisition_Agent_v1_*.zip`
- Demo lineage: `soren-spac-target-screening-demo/`, represented here only by `03_case_studies/soren_v1_final/demo_README.md`

- `01_business_workflow/` - methodology and workflow materials, including the Soren workflow diagram assets.
- `02_prompts/` - SPAC target acquisition prompt set.
- `03_case_studies/soren_v1_final/` - original mandate, derived mandate, SEC source anchor, final reports, selected evidence tables, and demo notes.
