→ Mandate Intake
→ SPAC Buyer Profile Construction
→ Investment Mandate Normalization
→ Industry Thesis Router
→ Data Source Registry Selection

## Notes
- The report screens U.S. private companies, not listed companies.
- OTC companies are excluded from the main target universe; they may appear only as watchlist / boundary cases / comps.
- Loss-making companies are allowed only if losses are controlled and there is evidence of revenue, growth, runway, or financing capacity.
- Industry focus is inferred from Soren's SEC filing and management/sponsor profile.
- Public/free sources only.
