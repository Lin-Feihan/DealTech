# Soren SPAC Target Screening Demo

## Public Demo Link

- Public demo: https://462852416-glitch.github.io/soren-spac-target-screening-demo/

## Demo Scope

The demo presents the Soren SPAC Target Acquisition Agent workflow, including mandate intake, workflow diagram, universe funnel, qualification matrix, target shortlist, and final report access.

## Technical Notes

- Public deployment is a static GitHub Pages demo.
- The formal agent repository does not include local server files, run scripts, duplicate deliverable demo folders, process logs, or regeneration scripts.
- The demo should be read as a presentation/testing surface. The formal agent repository is the workflow, prompts, Soren case report, original/derived input package, and selected supporting evidence tables retained in this repository.
- Ranking shown in the demo/report means screening priority and next-diligence priority, not a final investment recommendation or outreach-readiness claim.
