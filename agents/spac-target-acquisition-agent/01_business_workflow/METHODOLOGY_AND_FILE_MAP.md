# Methodology and File Map

This file replaces the methodology/file-map section that previously appeared in the final report. The final report remains a client-facing screening memo; implementation details live here.

## Core operating principle

The refreshed v1 process separates:

- **Method layer** — qualification gates, ranking, why-now scanning, transaction-feasibility checks, evidence labeling, and alternative-path analysis.
- **Delivery layer** — a professional memo that communicates conclusions without exposing internal prompt language.

## Changes reinforced in this pass

1. Section 5 now requires real company-level financial proxies or valuation ranges when available from runtime tables.
2. Section 5 write-ups must address six screening lenses directly: company characteristics, financial indicators, ownership/control, management/readiness, strategic synergy, and market/transaction feasibility.
3. Each shortlisted name should open with a bottom-line read explaining why the company is interesting, why it ranks where it does, and what still blocks sponsor-engagement confidence.
4. Company prose should translate public facts into judgment instead of reading like stitched-together source notes.
5. Universe Funnel counts must be derived from current run assets rather than copied from illustrative examples.
6. Export layout explicitly suppresses duplicate title blocks and reduces page-break whitespace around tables.
