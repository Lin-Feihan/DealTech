# Start Here - SPAC Target Acquisition Agent

This is the public agent repository view of the Soren SPAC Target Acquisition Agent.

## Review Order

1. `source_README_US_SPAC_v1.md` - source/provenance explanation.
2. `01_business_workflow/METHODOLOGY_AND_FILE_MAP.md` - methodology and file map.
3. `01_business_workflow/flowcharts/` - Soren workflow diagram assets, if present.
4. `02_prompts/` - SPAC target acquisition prompt set.
5. `03_case_studies/soren_v1_final/input/original_user_input/original_user_prompt.md` - original user mandate.
6. `03_case_studies/soren_v1_final/input/derived_mandate/` - structured mandate derived from the user prompt and SEC source.
7. `03_case_studies/soren_v1_final/reports/soren_initial_target_screening_report.md` - final public-facing case report.
8. `03_case_studies/soren_v1_final/evidence_tables/` - selected supporting tables for screening-level evidence and scoring.
9. `03_case_studies/soren_v1_final/demo_README.md` - public demo link and technical path notes.

## Curation Notes

- Raw notes, target-universe scratch files, process logs, regeneration scripts, local demo packages, and intermediate run folders are intentionally excluded from the formal agent repository.
- The retained evidence tables support the final screening report, but they do not turn the case into a completed diligence or investment recommendation.
- Public claims should keep the original caution: ranking means screening priority / next diligence priority, not final recommendation or outreach readiness.
