# Project Overview

Certified Deep Research Agents for AI-Native DealTech is a reusable framework for building deal-research agents whose outputs are traceable, evidence-linked, and subject to certification gates.

The repository currently contains four agent families:

1. Shell company screening / listed restructuring target screening.
2. SPAC target acquisition screening.
3. Acquisition strategy, with buyer-side and target-side views.
4. Merger strategy scaffold.

The aim is not to showcase demos. The aim is to make every output auditable: every material claim should connect to input setting, workflow step, source, evidence row, ER/BRB assessment, PCE result, and human-review status.
