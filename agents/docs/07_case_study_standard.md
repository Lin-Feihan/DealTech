# Case Study Standard

Every case study should include:

- `case_brief.md`
- `input_setting.md`
- `source_registry.md`
- `evidence_table.md`
- `research_trace.md`
- `ER_BRB_result.md`
- `PCE_result.md`
- `final_output.md`
- `limitations.md`

Acquisition strategy cases with multiple perspectives may nest these files under `buyer_side/` and `target_side/` while preserving a shared deal context.
