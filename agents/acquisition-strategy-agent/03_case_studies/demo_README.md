## Demo Scope

The public demo presents the Apple -> DarwinAI acquisition strategy case through two standalone pages:

- Buyer page: evaluates the acquisition from Apple's perspective.
- Seller / target page: evaluates the same transaction from DarwinAI's perspective.

Each page is locked to its own workflow, test case, flowchart, and report. The organized public demo replaces the earlier one-page dual-perspective prototype.

## Technical Notes

- Public deployment is static GitHub Pages HTML.
- The public static version does not include local server files, run scripts, backend endpoints, or bundled process artifacts.
- XBRL-related UI elements are represented as static explanatory notes and source references rather than live backend calls.
- The formal repository keeps only this demo reference README under the case study section; source/run artifacts are intentionally not included here.
