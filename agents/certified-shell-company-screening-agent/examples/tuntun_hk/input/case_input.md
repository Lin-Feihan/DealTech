# Case Input

## 1. Case Name

吨吨健康科技集团港股上市公司重组标的筛选  
Duntun Health HK Listed Restructuring Target Search

## 2. 案例主体

吨吨健康科技集团

## 3. 案例主体角色

吨吨健康科技集团为本次拟重组资产方。  
本次任务是为其寻找适合进行资产注入、业务整合、控股权交易或上市公司重组的港股上市公司平台。

内部分析可以评估反向收购或类似交易路径的可行性，但对外报告表述应优先使用“资产重组”“上市公司重组”“资产注入”“业务整合”“价值重塑”等表述，避免将项目简单表述为“借壳”或“找壳”。

## 4. 任务目标

基于港股公开资料和可获取数据，对香港联合交易所上市公司进行初步筛选，寻找可能适合吨吨健康科技集团进行资产注入、控股权交易、业务整合或上市公司重组的候选标的。

本次运行重点不是直接生成最终交易方案，而是先完成候选池构建、初步筛选、候选标的排序和待核验事项识别。

## 5. 本次筛选范围

本次筛选范围为香港联合交易所全部上市公司。

如因数据可得性、爬虫覆盖范围、公告格式、PDF 解析或资料缺失导致部分公司无法完整评估，应在运行结果中明确标注数据缺口、受影响字段和待人工核验事项。

## 6. 期望输出

输出一版港股上市公司重组标的初筛结果，包括：

1. 候选公司名单；
2. 初步推荐理由；
3. 主要风险；
4. 关键公开资料来源；
5. 初步协同方向；
6. 交易可行性初步判断；
7. 需要进一步人工核验的信息。

本阶段不要求生成最终交易方案，不得编造无法从公开资料确认的数据。


## 7. 本次运行边界

本次运行优先完成第一阶段筛选，不直接进入最终交易执行方案设计。  
如数据不足以支持 Top 3–5 推荐，应先输出数据缺口和下一步数据采集计划，而不是强行给出结论。
