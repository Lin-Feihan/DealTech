# Repository Curation Policy

This repository was rebuilt from earlier local project sources after the public DealTech repository appeared incomplete. The current public agent repository follows a strict curation rule: keep only high-value owner-made or collaborative materials, and remove process-heavy clutter.

## Curation Rules

- Keep the root `README.md` from `https://github.com/Lin-Feihan/DealTech` because the owner considers it carefully written.
- Do not use `Certified-Deep-Research-Agents-for-AI-Native-DealTech/` as a trusted canonical source.
- Do not use the later buyer-side acquisition loop agent as the canonical Acquisition Strategy Agent.
- Keep only the strongest workflow, prompt/spec, case-study, certification/evidence, and demo-link materials.
- Exclude drafts, placeholder files, raw caches, intermediate folders, process logs, duplicate demo packages, regeneration scripts, and one-off working papers from the formal public agent repository.
- Do not fabricate missing case studies. Merger Strategy remains framework-only until original source material is confirmed.

## Safety Rules

- Do not silently rewrite source claims.
- Do not upgrade screening-level material into investment, valuation, legal, or outreach-ready claims.
- If a canonical choice is uncertain, preserve the caution in the retained README/source note rather than inventing certainty.
- Push only after explicit owner approval.
